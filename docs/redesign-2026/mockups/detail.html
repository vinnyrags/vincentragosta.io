01 / Background

A long-running comedy institution needed a site that could keep pace with a live show.

Celebrity Autobiography — the Drama Desk–winning show where stars perform verbatim from the memoirs of the rich and famous — came to ARTHOUSE Interactive for a marketing site that could sell tickets, rotate an ever-changing celebrity lineup, and publish new performance dates without a developer in the loop.

The existing presence was on GoDaddy Managed WordPress: a closed hosting environment with no staging, no deploy workflow, and no room to grow.

“The brief: a fast, accessible single page with a self-serve calendar and cast grid, handed back to the marketing team for day-to-day updates.”
02 / Implementation

A provider-based build, engineered accessibility-first.

The site runs on my standard freelance architecture — the Mythus mu-plugin framework and IX parent theme, with a project-specific child theme on Timber/Twig and PHP 8.4.

03 / Infrastructure

Off Managed WordPress, onto a real deploy pipeline.

I migrated the property off GoDaddy onto a self-managed DigitalOcean droplet — nginx + PHP-FPM, a real staging environment, and a bare-repo post-receive hook that builds on every push.

~/projects/celebrityautobiography — deploy
$ git push production main
→ post-receive hook            ✓ received
→ composer install --no-dev    ✓ framework loaded
→ npm run build                ✓ assets compiled
→ wp cache flush               ✓ done
● live — celebrityautobiography.com
